Privacy Policy

Effective date: October 10, 2026

1. Overview

BloxShield (“BloxShield”, “we”, “us”) is a Discord bot that lets Roblox game owners moderate their games from Discord. This policy explains what data the bot processes, why, where it is stored, and the choices you have. It applies to Discord servers that use BloxShield (“customers”), their moderators, and the Roblox players moderated through it.

2. Data we process

Discord data

  • The ID of each Discord server (guild) that uses the bot, and the role IDs the server configures as moderator/admin roles.
  • The Discord user ID and username of moderators who run commands, so actions can be attributed (e.g. “banned by”) in logs and history.
  • Message content is read only in real time to detect a server's custom command prefix (for example !ban). It is not stored, logged, or used for any other purpose, and is discarded immediately after processing.

Roblox moderation data

  • Roblox user IDs and usernames of players that moderators look up, ban, kick, or unban.
  • Ban details: reason, duration, start/expiry time, whether alt accounts were included, and which moderator issued it.
  • Ban history for each player and daily moderation counters (number of bans, unbans, kicks).
  • In-game presence information written by the tracking script the customer installs in their own game: whether a player is currently in the game, their server ID, join time, and last-seen time.

Server configuration

  • Each customer's Roblox Open Cloud API key, universe ID, place ID, DataStore name, log webhook URL, command prefix, and role IDs.
  • Subscription records: server ID, subscription status and expiry date, and an optional administrative note.

3. How we use data

  • To perform moderation actions you request (ban, unban, kick, look up a player, show history and activity).
  • To show moderators accurate player and server information and keep an audit trail of actions.
  • To check subscription status and provide support.
  • To keep the service secure and prevent abuse.

We do not sell your data, use it for advertising, or use it to train machine-learning or AI models.

4. Where data is stored

  • Roblox DataStores: ban records, ban history, presence, and activity counters are written to a DataStore in the customer's own Roblox game via the Roblox Open Cloud API. The customer owns and controls that data.
  • Bot host: server configuration (including the Roblox API key) and subscription records are kept in configuration files on the server that runs the bot, accessible only to the BloxShield operator.

5. Sharing

We share data only as needed to make the service work, with the platforms it is built on: the Roblox APIs (to apply and read bans and DataStore entries) and Discord (to receive commands and send responses). Moderation log embeds are posted to the log webhook or channel the customer configures. We may disclose information if required by law. We do not share data with any other third parties.

6. Retention and deletion

  • Customers' administrators can delete a player's ban history from Discord (/clearhistory or the history panel).
  • Removing a server's configuration deletes its stored settings from the bot host. Data in the customer's Roblox DataStore can be deleted by the customer at any time.
  • To request deletion of data we hold about you or your server, contact us on the support server below.

7. Security

Access to configuration files is restricted to the operator, and API calls use HTTPS. We recommend customers create Roblox API keys limited to the permissions BloxShield needs and rotate them if they suspect exposure. No system is perfectly secure, and we cannot guarantee absolute security.

8. Children

BloxShield is operated by and for game moderators; it is not directed at children. Roblox players, who may include minors, are identified only by their public Roblox ID and username for moderation purposes. Discord requires its users to meet its minimum age.

9. Your choices

You can ask us to access, correct, or delete data we hold about you or your server, or stop using the bot by removing it from your Discord server and ceasing use of the tracking script.

10. Changes

We may update this policy. The effective date above shows when it was last changed; continued use of BloxShield after an update means you accept it.

11. Contact

Questions or requests: BloxShield Support Server (https://discord.gg/vjnKMR4wrw).

سياسة الخصوصية

تاريخ السريان: 10 أكتوبر 2026

1. نظرة عامة

BloxShield («نحن») بوت ديسكورد يتيح لأصحاب ألعاب روبلوكس إدارة ألعابهم والإشراف عليها من ديسكورد. توضح هذه السياسة البيانات التي يعالجها البوت، وسبب معالجتها، وأين تُخزَّن، والخيارات المتاحة لك. تنطبق على سيرفرات ديسكورد التي تستخدم BloxShield («العملاء») ومشرفيها واللاعبين الذين تتم إدارتهم عبره.

2. البيانات التي نعالجها

بيانات ديسكورد

  • معرّف كل سيرفر ديسكورد يستخدم البوت، ومعرّفات رتب المشرفين والإداريين التي يضبطها السيرفر.
  • معرّف مستخدم ديسكورد واسم المشرفين الذين ينفذون الأوامر، لنسب الإجراءات إليهم (مثل «تم الحظر بواسطة») في السجلات والتاريخ.
  • تُقرأ محتويات الرسائل لحظياً فقط للتعرف على بادئة الأوامر المخصصة للسيرفر (مثل !ban). لا يتم تخزينها ولا تسجيلها ولا استخدامها لأي غرض آخر، وتُتجاهل فور المعالجة.

بيانات الإشراف على روبلوكس

  • معرّفات وأسماء لاعبي روبلوكس الذين يبحث عنهم المشرفون أو يحظرونهم أو يطردونهم أو يرفعون الحظر عنهم.
  • تفاصيل الحظر: السبب، المدة، وقت البداية والانتهاء، وهل شمل الحسابات البديلة، والمشرف الذي أصدره.
  • سجل الحظر لكل لاعب وإحصاءات الإشراف اليومية (عدد الحظر ورفع الحظر والطرد).
  • معلومات التواجد داخل اللعبة التي يكتبها سكربت التتبع الذي يثبّته العميل في لعبته: هل اللاعب داخل اللعبة حالياً، ومعرّف السيرفر، ووقت الدخول، وآخر ظهور.

إعدادات السيرفر

  • مفتاح Roblox Open Cloud API الخاص بكل عميل، ومعرّف الـ Universe والـ Place، واسم DataStore، ورابط ويب هوك السجلات، والبادئة، ومعرّفات الرتب.
  • سجلات الاشتراك: معرّف السيرفر، حالة الاشتراك وتاريخ انتهائه، وملاحظة إدارية اختيارية.

3. كيف نستخدم البيانات

  • لتنفيذ إجراءات الإشراف التي تطلبها (حظر، رفع حظر، طرد، البحث عن لاعب، عرض السجل والنشاط).
  • لعرض معلومات دقيقة عن اللاعبين والسيرفرات للمشرفين والاحتفاظ بسجل تدقيق للإجراءات.
  • للتحقق من حالة الاشتراك وتقديم الدعم.
  • للحفاظ على أمان الخدمة ومنع إساءة الاستخدام.

نحن لا نبيع بياناتك ولا نستخدمها للإعلانات ولا لتدريب نماذج تعلّم الآلة أو الذكاء الاصطناعي.

4. أين تُخزَّن البيانات

  • Roblox DataStores: تُكتب سجلات الحظر وتاريخه والتواجد وإحصاءات النشاط في DataStore تابع للعبة العميل عبر Roblox Open Cloud API. العميل هو مالك هذه البيانات والمتحكم بها.
  • خادم البوت: تُحفظ إعدادات السيرفر (بما فيها مفتاح Roblox API) وسجلات الاشتراك في ملفات إعدادات على الخادم الذي يشغّل البوت، ولا يصل إليها إلا مشغّل BloxShield.

5. المشاركة

لا نشارك البيانات إلا بالقدر اللازم لعمل الخدمة مع المنصتين التي تقوم عليهما: واجهات روبلوكس (لتطبيق الحظر وقراءة بيانات DataStore) وديسكورد (لاستقبال الأوامر وإرسال الردود). تُنشر رسائل سجلات الإشراف في الويب هوك أو القناة التي يحددها العميل. وقد نفصح عن معلومات إذا ألزمنا القانون بذلك. ولا نشارك البيانات مع أي أطراف ثالثة أخرى.

6. الاحتفاظ والحذف

  • يستطيع إداريو العميل حذف سجل حظر أي لاعب من ديسكورد (/clearhistory أو لوحة السجل).
  • إزالة إعدادات السيرفر تحذف إعداداته المخزنة من خادم البوت. ويستطيع العميل حذف بيانات DataStore الخاصة بلعبته في أي وقت.
  • لطلب حذف بيانات نحتفظ بها عنك أو عن سيرفرك، تواصل معنا عبر سيرفر الدعم أدناه.

7. الأمان

الوصول إلى ملفات الإعدادات مقتصر على المشغّل، وتتم جميع طلبات الـ API عبر HTTPS. ننصح العملاء بإنشاء مفاتيح Roblox API بأقل الصلاحيات التي يحتاجها BloxShield وتغييرها عند الاشتباه في تسريبها. لا يوجد نظام آمن تماماً، ولا يمكننا ضمان أمان مطلق.

8. الأطفال

BloxShield مخصص لمشرفي الألعاب وليس موجهاً للأطفال. يتم التعرف على لاعبي روبلوكس، وقد يكون بينهم قاصرون، من خلال معرّفهم واسمهم العام فقط لأغراض الإشراف. وتشترط ديسكورد حداً أدنى للعمر لمستخدميها.

9. خياراتك

يمكنك طلب الاطلاع على بياناتك أو بيانات سيرفرك أو تصحيحها أو حذفها، أو التوقف عن استخدام البوت بإزالته من سيرفر ديسكورد وإيقاف سكربت التتبع.
